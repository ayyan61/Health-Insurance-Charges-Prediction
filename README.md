
 🏥 Medical Insurance Charges Prediction

Predicting medical insurance charges using Machine Learning techniques. This project analyzes key factors such as age, BMI, smoking habits, and region to estimate insurance costs accurately.

---

📌 Project Overview

This project focuses on understanding and predicting medical insurance charges using a dataset containing personal and demographic information. It includes complete data analysis, preprocessing, and regression modeling.

---
📊 Dataset Information

The dataset contains the following features:

* **age** – Age of the individual
* **sex** – Gender (male/female)
* **bmi** – Body Mass Index
* **children** – Number of dependents
* **smoker** – Smoking status (yes/no)
* **region** – Residential area
* **charges** – Medical insurance cost (target variable)

 📊 Key Insights

* Smoking significantly increases insurance charges
* BMI and age are strong predictors of cost
* Region has minimal impact compared to lifestyle factors

 🚀 How to Run


3. Install required libraries:
